書き込む保存先

このアプリはデータベースを持ちません。書き込み先はブラウザの localStorage と Cloudflare Workers KV（SAVED_ROUTES）の2つだけです。

保存先キー書き込む操作消えるとどうなるか
localStoragepp-origin / pp-dest / pp-award-kind / pp-partner-airline ルートを提案する ▶次回の検索条件が既定値に戻るだけ
localStoragem8f_savedこのルートを保存 / 🗑 / M2 保存 端末内の保存ルートが消える。同期トークンがあれば KV から復元できる
localStoragem8f_token同期トークンを保存 端末間の同期が切れる（端末内の保存ルートは残る）
localStoragem8f_award_type / m8f_group_primary_only / m8f_open_jaw ⚙ 設定設定が既定に戻るだけ
Workers KVSAVED_ROUTES['routes'] このルートを保存 / 🗑 / M2 保存（いずれも PUT /saved-routes） 全端末の保存ルートが消える。1件の削除でも全件を上書きする実装なので、競合時は後勝ち

動線の穴と、その是正

チェックリスト6項目を機械的に点検して4件を検出し、同じ日にすべて是正しました（REQ-91〜94）。何が起きていたかは記録として残します。

⚠-1 是正済み / REQ-91全画面がURLを持たず、再読込で必ず S1 に戻る

ppGo()（index.html:3942）は hidden を付け外しするだけで履歴を積みません。 組みかけの旅程・出した候補・開いていた旅程は、再読込した瞬間に全部消えます。

スマホでは別アプリに切り替えただけでタブが再読込されることがあり、 ANAの予約画面と往復しながら使う場面で、戻るたびに条件入力からやり直しになります。

直した内容：history.pushState で画面IDを #s2 等として積み、 popstate で ppGo を呼ぶ。S1の入力は既に localStorage にあるので復元は安い。

⚠-2 是正済み / REQ-92「◀ 提案に戻る」の戻り先が固定

S4 の戻るボタンは常に ppGo('s3')（index.html:1034）。 保存ルートの読込など S3 を経ずに S4 を開いた場合、中身が空の S3 に着地します。

直した内容：直前の画面を覚えて戻す。または S3 が空なら S2（無ければ S1）へ落とす。

⚠-3 是正済み / REQ-93文言だけが案内していて、実際には行けない

S1 のヒント（index.html:956）が「変えたいときは下の『じぶんで組む』で指定してください」と案内していますが、 S1 に「じぶんで組む」へ行くボタンはありません（grep で 0 件を実測）。

2026-09-09 に「画面をいちどに1つだけ出す」へ変えたとき、S4 は S1 の「下」ではなくなったのに文言が残りました。 実際に S4 へ行くには S1 → S2 → S3 →「この旅程を『じぶんで組む』に読み込む」 の3手が必要です。

直した内容：さがす画面に入口を新設し、位置に依存した「下の」という言い方をやめた。

⚠-4 是正済み / REQ-94「特典の種類」が2か所にあり、意味が違う

S1 の「特典の種類」は3択（スターアライアンス／提携航空会社1社／ANA便のみ）で探索の絞り込み。 S4 設定の「特典航空券タイプ」は2択（提携／ANA便のみ）で規約カードの表示と判定。 名前が似ているため、片方を変えればもう片方も変わると誤解しえます。

直した内容：設定側の見出しを「どちらの規約で判定するか」に変え、「特典の種類」との違いを注記した。 S4 → S1 へ移るとき partner を star として開く扱いは従来どおり。

✅ 点検して問題が無かった項目

権限による死に導線：該当なし（認証が無く、全員が全画面を使える）。
押せない導線の理由表示：対処済み。📅ボタンは Chrome拡張が無いとグレーアウトし、理由を文章で出す。
入口の重複：S2 → S1 が「条件チップ」と「◀ 条件を変える」の2つ。どちらも同じ行き先で害がないため意図的と判定。
